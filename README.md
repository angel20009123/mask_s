# Mask Studio

中文 Windows IPv4 掩码与 ACL 通配符计算器，支持非连续通配符、多范围条件反推与彩色子网层级展示。计算在本地完成，不需要登录，也不需要联网。

**当前版本：v1.2.0** · [下载 Windows 客户端](https://github.com/angel20009123/mask_s/releases/latest) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/angel20009123/mask_s/issues)

## 快速开始

1. 在 [Releases](https://github.com/angel20009123/mask_s/releases) 中下载 `MaskStudio-v1.2.0.exe`。
2. 双击运行，无需安装 Python。当前发布目标为 Windows x64。
3. 在顶部输入 IPv4 地址，选择 CIDR、正掩码或反掩码，点击“计算结果”；需要从地址范围反推规则时，切换到“地址范围反推”页。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 掩码互转 | CIDR 前缀、正掩码、反掩码 / ACL 通配符及二进制展示 |
| 网段计算 | 网络地址、广播地址、可用地址范围和地址数量 |
| 非连续通配符 | 精确拆分 CIDR 子网，按地址层级展示，支持分页 |
| 多范围反推 | 多条起止地址条件，自动合并重叠、重复及相邻范围 |
| 匹配检查 | 检查地址是否匹配，多条件模式显示命中的条件编号 |
| 结果复制 | 复制掩码结果，或全部范围条件及 ACL 规则 |

蓝色表示固定匹配位，紫色表示非连续分支位，绿色表示连续地址位。范围条件与结果采用不同底色，子网分组节点可以展开、折叠。

## 使用示例

### 地址与掩码互转

输入地址 `192.168.1.10`，选择“CIDR 前缀”，输入 `24`：

| 项目 | 结果 |
| --- | --- |
| 正掩码 | `255.255.255.0` |
| 反掩码 / 通配符 | `0.0.0.255` |
| 网络地址 | `192.168.1.0` |
| 广播地址 | `192.168.1.255` |
| 可用地址 | `192.168.1.1` ～ `192.168.1.254`，共 254 个 |

### 非连续 ACL 通配符

输入地址 `192.168.0.0`，选择“反掩码 / ACL 通配符”，输入 `0.0.5.255`。在“子网层级与地址范围”中，会看到两个精确匹配的子网：

| CIDR | 实际匹配范围 |
| --- | --- |
| `192.168.0.0/23` | `192.168.0.0` ～ `192.168.1.255` |
| `192.168.4.0/23` | `192.168.4.0` ～ `192.168.5.255` |

中间的 `192.168.2.0/23` 不匹配。点击“载入非连续 ACL 示例”可直接查看。

### 多条范围条件反推

1. 进入“地址范围反推”。列表初始有一条示例条件，可以选中后修改或删除。
2. 输入起始地址、结束地址，点击“添加条件”；重复操作即可添加多条。
3. 选中一条后修改输入框，再点击“更新选中条件”。Ctrl / Shift 可多选后删除。
4. 点击“反推全部条件”，查看 CIDR、正掩码、反掩码及实际范围。
5. 底部输入待检查地址，点击“检查地址”；“复制结果”会复制所有已添加条件及完整规则。

条件之间是**或关系**：满足任意一条即匹配。起止地址均包含在范围中。输入框为编辑器，只有列表中的条件参与计算；修改输入框后需要添加或更新条件。

例如添加两条条件：

| 条件 | 起始地址 | 结束地址 |
| --- | --- | --- |
| 1 | `192.168.1.0` | `192.168.1.255` |
| 2 | `192.168.3.0` | `192.168.3.255` |

反推结果为两条精确规则，合计 512 个地址：

```text
192.168.1.0 0.0.0.255
192.168.3.0 0.0.0.255
```

`192.168.3.100` 命中条件 2；`192.168.2.100` 不匹配。重叠范围按并集去重，不重复计算地址数量。

## 计算规则与边界

- ACL 通配符二进制位：`0` 表示必须匹配，`1` 表示忽略该位。反掩码为正掩码逐位取反。
- 正掩码必须是连续的 1 后接连续的 0。非连续 ACL 通配符的取反值不属于合法的单个子网掩码。
- 非连续通配符的最小、最大匹配地址之间可能存在不匹配地址；分组节点仅用于展示，不代表整组均匹配。
- 范围反推生成精确覆盖并集的最少 **CIDR** 规则，不进行允许非连续通配符时的全局最少 ACL 规则优化。
- 网段可用地址数量：`/31` 按点对点网络处理为两个地址；`/32` 为一个主机地址。ACL 匹配本身包含网络地址及广播地址。
- ACL 输出为“地址 + 通配符”片段。实际设备还需要配置 permit / deny、协议和方向，语法以设备说明为准。
- 支持 IPv4；多范围条件当前支持或关系，不提供排除条件、与关系或 IPv6。
- 非连续通配符子网每页最多 128 条；该模式复制包含当前页子网，并标注总数与页范围。多范围反推复制完整规则。

## 从源码运行与打包

运行环境：包含 Tkinter 的 Python 3.10 或更高版本。客户端运行不依赖第三方 Python 包。

```powershell
python app.py
python -m unittest -v
```

Windows 也可双击 `启动客户端.bat` 运行源码。打包独立 EXE：

```powershell
python -m pip install pyinstaller==6.22.3
python build.py
```

输出为 `dist/MaskStudio-v1.2.0.exe`。版本号从 `version.py` 统一读取，并写入窗口标题、文件名和 Windows 文件属性。重新生成图标时需安装 Pillow，再运行 `python create_assets.py`。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `app.py` | Tkinter 界面、条件编辑和结果展示 |
| `calculator.py` | 掩码运算、匹配检查、非连续子网分页和范围并集分解 |
| `test_calculator.py` | 计算边界、精确覆盖和多条件合并测试 |
| `version.py` | 应用版本号 |
| `build.py` | Windows EXE 打包与版本资源生成 |
| `assets/`、`create_assets.py` | 图标文件及可复现生成脚本 |
| `.github/workflows/release.yml` | 推送版本标签后自动测试、构建和发布 |

## 版本发布

采用 `主版本.次版本.修订版本`：问题修复增加修订版本，新增功能增加次版本，不兼容改动增加主版本。更新 `version.py`、本说明的版本及文件名，并在 `CHANGELOG.md` 记录变更。

新版本完成测试和本地打包后，代码自动同步到 GitHub，并推送 `vX.Y.Z` 标签。GitHub Actions 校验标签、运行测试、生成 Windows EXE 并发布到 Releases。历史版本保留，已发布标签不覆盖；构建中间文件和 EXE 不直接提交到源码仓库。

反馈问题时请提供客户端版本、输入条件、预期结果和实际结果。示例地址请使用脱敏数据。
